# Сайт «Ваза»

Адаптивный сайт-презентация по образцу kirby3d994.github.io/Kirby: тема заменена на вазы, палитра — бирюзово-мятная, добавлен интерактивный 3D-просмотр и скрытая админ-панель.

## Запуск

Откройте `Запустить сайт.bat` — браузер откроет `http://localhost:8000/`. Сервер написан на PowerShell, дополнительное ПО не требуется.

Важно: 3D-модель загружается через веб-сервер. Прямое открытие `index.html` через `file://` может заблокировать загрузку файлов.

## Структура

- `index.html` — разметка, все тексты помечены `data-edit`, картинки — `data-image`.
- `style.css` — оформление, цвета заданы CSS-переменными в `:root`.
- `script.js` — 3D-сцена на Three.js, анимации, светbox и админ-панель.
- `site-config.js` — опубликованные настройки; сейчас указывает на анимированную вазу.
- `assets/` — SVG-иллюстрации и ваша 3D-модель.

## Как добавить свою 3D-модель

1. Сейчас подключён `assets/vase_animated.glb` — модель с вращением и запечённой процедурной текстурой (`assets/vase_texture.png` встроен в GLB). Рядом лежит редактируемый `assets/ваза прайм.blend` с анимацией `PlaneAction`.
2. Вкладка «🎬 Анимация» показывает ту же вазу с файлом `assets/vase-sway.glb` (копия `ваза прайм покачивание.glb`) — он содержит только движение, геометрия берётся из `vase_animated.glb`.
3. Откройте сайт, нажмите `Ctrl` + `Shift` + `A` (или добавьте `?admin=1` к адресу).
4. Вкладка **3D-модель** → укажите путь к файлу → **Применить**.
5. Там же можно временно загрузить файл с компьютера для предпросмотра.

Если экспортируете сами: включайте **Apply Modifiers** и **Animations**, иначе в GLB не будет меша или вращения. Процедурные текстуры Blender (Wave, ColorRamp) в glTF не переносятся — их нужно запечь в изображение, как это сделано здесь.

Поддерживаются `.glb`, `.gltf`, `.obj`, `.stl`; анимации воспроизводятся из GLB/GLTF. Вкладка «Облёт камеры» удалена — остались «3D-модель» и «Анимация». Если файла нет или он не загрузился, показывается процедурная ваза на Three.js и запасная CSS-ваза.

## Админ-панель

Открывается скрыто: `Ctrl` + `Shift` + `A` или `?admin=1` в адресе. После первого открытия кнопка ⚙ появляется в правом нижнем углу.

Вкладки:

- **Тексты** — кнопка «Редактировать тексты» включает правку прямо на странице; «Готово — сохранить» сохраняет изменения.
- **Цвета** — меняет любые цвета темы мгновенно.
- **Картинки** — замена изображений по ссылке или файлом с компьютера.
- **3D-модель** — путь, масштаб, автовращение, тестовый файл.
- **Публикация** — скачать `site-config.js`, загрузить конфиг, сбросить изменения.

Изменения в панели сохраняются в браузере как черновик. Чтобы их увидели **все пользователи**, скачайте `site-config.js` кнопкой «⬇ Скачать site-config.js» и замените одноимённый файл на сайте/хостинге.

> Панель скрыта от обычных посетителей, но не защищена паролем — это демонстрационное решение. Для настоящей защиты нужен сервер с авторизацией.
